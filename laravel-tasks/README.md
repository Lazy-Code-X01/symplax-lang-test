# laravel-tasks

A small but real Laravel app for testing Symplax: Blade with Vite, Postgres,
database sessions/cache/queue, and a queued job run by a worker.

On Symplax:

- Root directory: `laravel-tasks`
- Link a PostgreSQL database (gives `DATABASE_URL`, mapped to Laravel's `DB_URL`)
- Release command: `php artisan migrate --force`
- Worker: `queue`, command `php artisan queue:work --tries=3`
- `APP_KEY` is generated by Symplax

Add a task: it shows "waiting for worker" until the worker processes it, then
"processed by <container>". `/api/stats` shows PHP, driver, queue and job counts.
